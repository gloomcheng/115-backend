# Layout contract template

Create one contract per approved direction. A contract is a build specification, not a
moodboard.

## 2. Composition

- Desktop grid: column count, max width, margins, and main alignment axis.
- Mobile transformation: what stacks, what scrolls, and what remains persistent.
- First three eye stops:
- Dense zone and quiet zone:

## 3. Type and color roles

- Display role: actual installed or hosted font, size range, weight, line-height.
- Reading role: actual installed or hosted font, size range, line-height.
- Evidence role: code/metadata font and its permitted locations.
- Surface, ink, muted text, divider, action, and state colors.

## 4. Components

- Header/navigation location and behavior.
- Section transition treatment.
- List, card, callout, and code-block treatment.
- Image/diagram location, size, caption, and mobile behavior.

## 5. Explicit exclusions

List patterns that would contradict the direction: for example, boxed-card grids,
hero photography, faux paper texture, drop shadows, centered titles, or oversized
display type. The exclusions must be specific to this contract.
