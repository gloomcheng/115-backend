# Japanese web award reference library

The full, reproducible library is
[`../resources/japanese-web-awards.json`](../resources/japanese-web-awards.json).
It contains the maintained Web Grand Prix winner list, refreshed by
`npm run research:japan-web:refresh` and validated by
`npm run research:japan-web:check`.

## Required reference-board process

Before any new visual system or route layout:

1. Read the corpus and select three references with different functions: one visual
   grammar, one information architecture, and one task/action pattern.
2. Capture each source at the target desktop viewport. Do not judge from a search
   thumbnail or memory.
3. Produce a direction board containing source URL, screenshot, reader task, visual
   rules that may transfer, and protected features that must not transfer.
4. Present the three directions to the user. Do not edit the product until one
   direction, or a named combination, is approved.
5. Turn only the approved transferable rules into a route-specific layout contract.

The user approves a direction, not a vague regional or cultural style. A rejected
direction stays recorded as rejected and must not become a token or default later.
