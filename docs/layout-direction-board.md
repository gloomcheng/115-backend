# 115 Backend — layout direction board

These are three distinct directions selected from the researched award corpus. They
preserve the existing course copy and do not reuse a reference’s logo, artwork, or
typeface.

## A. Material threshold

Reference: [紡ぐ TSUMUGU](https://tsumugu.yomiuri.co.jp/), Web Grand Prix 2020 B2C winner.

- Entry: a quiet image/material field before any menu or course claim.
- Grid: content appears after a deliberate threshold; metadata remains peripheral.
- Type: modest label, then a single reading block.
- Color: near-white field and subdued ink; no interface chrome in the first view.
- Course translation: the first raw HTTP Request becomes the threshold image rather
  than a headline; the learner enters through one visible packet.
- Risk: material atmosphere can weaken the course’s first action and make the site
  feel like an exhibition catalogue rather than a teaching tool.

## B. Graphic coordinate

Reference: [コクヨのヨコク](https://brand.kokuyo.co.jp/), Web Grand Prix 2023 corporate-site winner.

- Entry: large empty field with one or two deliberately displaced graphic masses.
- Grid: edges and off-canvas crops provide orientation instead of divider lines.
- Type: short labels are attached to a graphic coordinate; large text is not a
  conventional centered hero.
- Color: a highly limited set of intentional color blocks; no gradients, shadows, or
  card surfaces.
- Course translation: one red dot is the coordinate; a single black Request/Response
  strip is the only other graphic mass. Chapters become displaced anchors on a map,
  not four cards or a table.
- Risk: the graphic system can overwhelm the beginner’s reading task unless the raw
  HTTP evidence remains dominant.

## C. Task gate

Reference: [熊本県立高校検索ガイド](https://kumamoto-pref-hs.jp/), Web Grand Prix 2022 B2C winner.

- Entry: one unmissable primary task; navigation and search are explicit, not hidden.
- Grid: a large active field creates momentum, with secondary information below.
- Type: high contrast and a clear action hierarchy.
- Color: high contrast is used to direct action, not to decorate every component.
- Course translation: the first task is `curl -v`; the home page begins with the
  runnable evidence and only then exposes the eighteen-week map.
- Risk: a task-first gate could turn a course into a campaign landing page and lose
  the long-form course context.

## Recommendation — rejected

The proposed combination of **B as the visual grammar** and **C as the navigation grammar** was not approved. Do not implement or refine it.

- one red coordinate only;
- open field, no cards, no divider-based sectioning;
- no huge generic hero headline;
- raw HTTP text is the first meaningful graphic object;
- one explicit next action;
- chapter groups become spatial anchors, while the full schedule stays readable as a
  secondary map.

Do not apply direction A to this course. Its material-first entrance conflicts with
the course requirement to show the wire and a runnable command immediately.
