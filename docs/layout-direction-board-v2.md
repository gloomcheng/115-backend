# 115 Backend — direction board v2

This board supersedes the rejected B＋C direction. It uses three newly inspected Web
Grand Prix references and preserves every existing course string.

## A. Civic storybook

Reference: [がいしの歴史](https://www.ngk.co.jp/gaishi-h/), Web Grand Prix 2021 B2B winner.

- Composition: one illustrated or symbolic world introduces a long story; secondary
  navigation is quiet and appears after the entry scene.
- Color: a limited historic palette with one dominant ground and one dark line color.
- Course translation: one oversized raw HTTP packet becomes the entry scene. Client,
  Server and Browser become simple outlined figures on the same field.
- Information flow: scene → one claim → chronological chapters.
- Prohibited: historic mascot illustration, literal electrical icons, decorative
  storytelling unrelated to HTTP.

## B. Material index

Reference: [日本紙パルプ商事](https://www.kamipa.co.jp/), Web Grand Prix 2019 corporate-site winner.

- Composition: a calm functional home, with content areas inheriting a material logic
  rather than generic white cards.
- Color: restrained industrial neutrals; material changes signal category changes.
- Course translation: chapters become four material modes—wire, record, boundary and
  runtime—without inventing new product labels. The raw packet is a repeated object
  that changes state through the course.
- Information flow: one topic surface → selected route → evidence.
- Prohibited: fake paper texture, poster ratio imitation, decorative company history.

## C. Flowing evidence

Reference: [株式会社 明治](https://www.meiji.co.jp/), Web Grand Prix 2021 accessibility winner.

- Composition: a broad calm canvas holds independently placed content blocks; one
  curved colored path relates them without boxing them into a grid.
- Color: pale neutral field, a single brand red curve, natural image blocks.
- Course translation: Request → Server → Response → Screen is the single curve. The
  curve is structural, not decoration; every content island sits on a real stage of
  that flow.
- Information flow: one path → task entry → related evidence islands → route map.
- Prohibited: lifestyle photography, brand-red reproduction, extra curves, content
  blocks that are not attached to the HTTP flow.

## Recommended contract to approve

**C’s flowing evidence layout with A’s outlined technical objects.**

- Background: a cool, pale blue-gray field; ink-black text; exactly one red path.
- Main composition: no giant headline. A large raw `GET /health` packet begins at the
  left; the existing course title and description occupy the central reading island;
  the existing current lesson sits at the right endpoint.
- Objects: outlined terminal, server and browser only where they explain ownership of
  a Request or Response; no mascots or decorative illustrations.
- Course map: chapter groups branch from the same route as small information islands,
  not cards and not a table surrounded by dividers.
- Mobile: the path becomes vertical; each island follows the same causal order.

## Rejected directions

- Original magazine cover/capsule/card system.
- Divider-based field map.
- B＋C graphic coordinate/task gate implementation.

No rejected direction may be refined or reused without a new explicit approval.
